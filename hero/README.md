# Imágenes destacadas

Guarda aquí tus imágenes con el nombre del paquete de la app: un archivo como `com.esaba.downloader.jpg` para una sola,
o una carpeta `com.esaba.downloader\` con varias, que rotan. Súbelas con `scripts\push-heroes.ps1`. Git ignora esta
carpeta salvo este archivo: las imágenes no se publican.
